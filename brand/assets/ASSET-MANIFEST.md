## Usage rule

Never regenerate the LORE logo inside a card illustration. Composite the approved asset over finished artwork. This prevents design drift between creators, rarities, packaging and digital surfaces.

## Repository upload note

The GitHub connector currently exposes UTF-8 file writes and Git object operations but does not accept local binary file references directly. The PNG files must therefore be uploaded to this `brand/assets/` folder from the prepared asset bundle. The SHA-256 values above verify that the correct files were uploaded.
