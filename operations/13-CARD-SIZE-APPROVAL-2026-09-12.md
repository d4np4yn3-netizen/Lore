# Standard card size approval — 12 September 2026

Daniel asked whether LORE would use the standard size of Pokémon and Magic: The Gathering cards. The response specified **63 × 88 mm** and explained that the visual design was locked while physical dimensions remained pending.

Daniel then explicitly approved that proposal: “Ok let’s lock the lock this in if we are the same as a Pokémon standard card”.

The [manufacturer's size reference](https://printninja.com/card-dimensions/) identifies Pokémon and Magic: The Gathering's standard TCG size as 63 × 88 mm. This condition supports locking the proposed metric format.

## Decision

- **LORE-SIZE-v1.0: 63 mm width × 88 mm height after cutting.**
- The same size applies to every standard LORE card, on front and back, across creators and rarities.
- Preserve the approved LORE-FRONT-v3 and LORE-BACK-v5 visual masters; create separate printer-specific derivatives later.
- This resolves the physical-dimensions item left open in the previous [back approval](12-SHARED-BACK-V5-APPROVAL-2026-09-12.md).
- Bleed, safe inset, corner radius, cutting tolerance, stock, finishes and physical print/QR proof remain open. These are not set by the nominal card size.

See [the physical size standard](../cards/09-PHYSICAL-SIZE-STANDARD.md) and [current card design lock](../cards/card-design-lock.json).
