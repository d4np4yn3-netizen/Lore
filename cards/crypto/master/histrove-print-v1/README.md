# HISTROVE print master

Approved 6 October 2026. Use these six rarity templates for new numbered Crypto print cards. The geometry is exactly LORE print v1.2; only the top-right brand layer is replaced by the approved HISTROVE compact lockup. No front tagline. The shared back includes History Worth Holding at 6.48 pt.

Use [print-spec.json](print-spec.json), [approval.json](approval.json), [templates](templates) and [source/render_print_card.py](source/render_print_card.py). The renderer uses the repository-pinned fonts in cards/master/front-v3/source and produces 816 × 1110 PNG at 300 DPI. Use [source/export_print_pdf.py](source/export_print_pdf.py) for the matching outlined-text PDF with explicit trim and bleed boxes. Keep original artwork bytes and confirm the QR route before rendering. No 600-DPI native-resolution claim is made.

Historical templates remain in ../print-v1.2. Preserve original visual/card/art references; do not regenerate complete cards. Printer/sample acceptance remains a separate gate.
