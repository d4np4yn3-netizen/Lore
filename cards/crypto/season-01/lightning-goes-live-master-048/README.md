Approved Storm Guardian anime v2, 8 October 2026. BITCOIN / Uncommon / 15 MAR 2018 / THE VERY BEGINNING. / 048/100.

The exact approved art and card pixels are retained. The print front is 816 × 1110 at 300 DPI; web display uses a separate 744 × 1038 trim crop. See approval.json, card-final-qa.json, book-qa.json, source-notes.md, sources.json, closeup-boxes.json and publication-verification.json for the separate historical, visual, digital-publication and physical-print statuses. Physical print acceptance, book-resolution review and rights clearance are not implied.

Reproduction: source/build_card.py verifies the pinned master/fonts and exact artwork before rendering. Pass --repo-root for the repository root. build_book.py reproduces the unchanged A4 layout from the shared story/clue JSON and native art. The original PNG, SVG and PDF are sealed delivery assets; rebuilding can change container metadata even when visual pixels match.
